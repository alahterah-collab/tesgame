# Asset notes

The included 2048×2048 WebP surface maps under `public/assets/textures/` are local game assets for Aetherion Online. The runtime does not fetch the texture maps from remote hosts. Three.js is installed as a project dependency and bundled by Vite for production builds.

Files include albedo/color, normal, and roughness maps for forest floor, muddy path, tree bark, foliage, and stone, plus normal/roughness maps for water.
